# استودیو نگاهم — وب‌سایت + پنل مدیریت

وب‌سایت استودیوی تبلیغاتی با یک پنل مدیریت کامل و اختصاصی. طراحی‌شده برای اجرا روی **IIS** (از طریق Node.js + ریورس‌پروکسی).

## امکانات

**سایت عمومی**
- صفحه خانه با هیرو انیمیشنی، مارکی برندهای کارفرما، نمونه‌کارهای برتر
- صفحه «کارفرمایان» با گرید حرکتی و فیلتر بر اساس صنعت (ورود/خروج انیمیشنی کارت‌ها)
- صفحه اختصاصی هر کارفرما با دسته‌بندی نامحدود نمونه‌کار (مثلاً «کمپین تبلیغاتی»، «طراحی سایت»، هرچی که در ادمین اضافه کنی)
- صفحه هر دسته‌بندی با گالری + لایت‌باکس
- صفحه «درباره ما» و «تماس با ما» (فرم واقعی که پیام‌ها را در پنل مدیریت ذخیره می‌کند)
- انیمیشن‌های GSAP + Lenis (اسکرول نرم)، ترنزیشن بین صفحات، کرسر سفارشی، افکت‌های هاور
- کاملاً راست‌به‌چپ (RTL) و فارسی، فونت پیش‌فرض Vazirmatn

**پنل مدیریت (`/admin`)**
- ورود امن با نام‌کاربری/رمزعبور + امکان تغییر رمز
- تنظیمات ظاهری: رنگ‌های سایت (پس‌زمینه، متن، اصلی، ثانویه، تاکیدی)، آپلود فونت اختصاصی (woff2/woff/ttf/otf) و انتخاب فونت فعال، آپلود لوگو/فاوآیکون
- ویرایش متن‌های صفحه خانه، درباره ما، تماس با ما، شبکه‌های اجتماعی
- مدیریت کامل کارفرماها: افزودن/ویرایش/حذف، انتشار/پیش‌نویس، ویژه‌کردن، ترتیب نمایش
- برای هر کارفرما: تعداد نامحدود دسته‌بندی نمونه‌کار + آپلود تصویر/ویدیو برای هرکدام، امکان مشخص‌کردن نمایش در «نمونه‌کارهای برتر» صفحه اصلی
- صندوق پیام‌های تماس با ما (خوانده/نخوانده، حذف)

## اجرا روی سیستم خودت (توسعه)

نیازمندی: **Node.js نسخه ۲۲ یا بالاتر**

```bash
npm install
node scripts/seed.js   # فقط بار اول - محتوای نمونه می‌سازد (اگر کارفرمایی وجود نداشته باشد)
npm run dev
```

سایت روی `http://localhost:3000` بالا می‌آید.

### ورود به پنل مدیریت

آدرس: `http://localhost:3000/admin`

نام‌کاربری و رمز پیش‌فرض (در اولین اجرا در کنسول هم چاپ می‌شود):

```
نام‌کاربری: admin
رمز عبور:   Negaham@2026
```

⚠️ **حتماً بلافاصله بعد از اولین ورود، از بخش «تنظیمات سایت → امنیت حساب» رمز را عوض کن.**
برای تغییر نام‌کاربری/رمز پیش‌فرض قبل از اولین اجرا هم می‌تونی متغیرهای محیطی `ADMIN_USERNAME` و `ADMIN_PASSWORD` را ست کنی (پایین‌تر توضیح داده شده).

## متغیرهای محیطی

یک فایل `.env.local` (برای توسعه) یا `.env` (برای پروduction) بساز:

```env
# کلید امضای نشست ورود ادمین - حتما یک مقدار طولانی و تصادفی بگذار
SESSION_SECRET=یک-رشته-طولانی-و-تصادفی-اینجا

# فقط برای اولین اجرا استفاده می‌شود (ساخت کاربر ادمین پیش‌فرض)
ADMIN_USERNAME=admin
ADMIN_PASSWORD=یک-رمز-قوی-بگذار

PORT=3000
NODE_ENV=production
```

## دیتابیس و فایل‌های آپلودی

این پروژه از **SQLite** استفاده می‌کند (بدون نیاز به نصب هیچ دیتابیس جداگانه‌ای). همه‌چیز — دیتابیس و فایل‌های آپلودی (تصویر/فونت) — در پوشه‌ی:

```
data/
├── studio.db          # دیتابیس
└── uploads/
    ├── images/
    └── fonts/
```

ذخیره می‌شود. این پوشه در گیت ignore شده چون داده‌ی زنده‌ی سایت است، نه کد.

**نکته مهم:** موقع بکاپ‌گیری از سایت، حتماً پوشه‌ی `data/` را هم بکاپ بگیر — تمام اطلاعات کارفرماها، نمونه‌کارها، تنظیمات و پیام‌ها همین‌جاست.

## ساختار پروژه (خلاصه)

```
src/
├── app/
│   ├── (site)/         صفحات عمومی سایت (خانه، درباره، تماس، کارفرمایان)
│   ├── admin/           پنل مدیریت
│   ├── api/             تمام API روت‌ها (ادمین + فرم تماس)
│   └── uploads/[...path] سرو کردن فایل‌های آپلودی به‌صورت پویا
├── components/
│   ├── site/            کامپوننت‌های سایت عمومی (انیمیشن، هدر، گالری...)
│   └── admin/            کامپوننت‌های پنل مدیریت
├── lib/
│   ├── db.ts             اتصال SQLite + اسکیمای دیتابیس
│   ├── queries.ts        تمام کوئری‌های دیتابیس
│   ├── auth.ts / auth-edge.ts   احراز هویت پنل مدیریت
│   ├── theme.ts           تولید CSS رنگ/فونت داینامیک از تنظیمات
│   └── uploads.ts         ذخیره فایل آپلودی
scripts/seed.js            ساخت محتوای نمونه برای شروع سریع
```
