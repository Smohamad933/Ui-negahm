# ابزار ساخت CSS (فقط برای توسعه، نه برای اجرای واقعی سایت)

این پوشه یک ابزار محلی و یک‌بارمصرف است؛ روی سرور IIS به آن نیازی نیست و
Node.js هم در زمان اجرای واقعی سایت لازم نمی‌شود. خروجی نهایی همین حالا در
`../public/css/app.css` و فونت‌ها در `../public/fonts/` آماده و کامیت‌شده‌اند.

این پوشه فقط برای زمانی لازم می‌شود که بخواهید کلاس‌های Tailwind جدیدی به
فایل‌های Blade اضافه کنید و لازم باشد فایل CSS دوباره ساخته شود.

## نحوه ساخت مجدد CSS

```bash
cd laravel-app/.assets-build
npm install
npm run build
```

خروجی در `../public/css/app.css` بازنویسی می‌شود. فونت‌های خوداستایل‌شده
(Vazirmatn و Manrope با فرمت Variable) هم به‌صورت فایل‌های ثابت woff2 در
`../public/fonts/` قرار دارند و در `src/fonts-*.css` به آن‌ها ارجاع داده
می‌شود؛ برای تغییر فونت پیش‌فرض سایت نیازی به این پوشه نیست — از پنل مدیریت
(تنظیمات → رنگ و فونت) یک فونت سفارشی آپلود کنید.

## چرا این‌طور طراحی شده؟

Laravel روی IIS با PHP خالص (بدون Node.js/iisnode) اجرا می‌شود، بنابراین
Tailwind CLI نباید در زمان اجرا لازم باشد. به همین دلیل ساخت CSS یک مرحله‌ی
جدا و محلی (build-time) است، نه بخشی از اجرای برنامه.
