# Ui-negahm

وب‌سایت و پنل مدیریت استودیو تبلیغاتی «نگاهم».

کد اصلی پروژه داخل پوشه‌ی [`studio/`](./studio) قرار دارد. برای راه‌اندازی و مستندات کامل به [`studio/README.md`](./studio/README.md) و برای راهنمای انتشار روی سرور IIS به [`studio/DEPLOY.md`](./studio/DEPLOY.md) مراجعه کن.

راه‌اندازی سریع:

```bash
cd studio
npm install
node scripts/seed.js
npm run dev
```
