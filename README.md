# نگاه مدیا (negahm.ir) — وب‌سایت و پنل مدیریت

وب‌سایت شرکتی و پنل مدیریت آژانس تبلیغاتی «نگاه مدیا»، ساخته‌شده با
**PHP خالص (بدون فریم‌ورک) + SQLite** برای اجرای بومی روی **IIS** (بدون
نیاز به Node.js، Composer، `vendor/`، `artisan` یا هیچ مرحله‌ی build/نصب
دیگری).

> نسخه‌های قبلی این پروژه با Next.js/Node.js و سپس با Laravel ساخته شده
> بودند؛ به دلیل مشکلات مکرر استقرار روی هاست‌های اشتراکی IIS (نیاز به
> Composer، artisan، URL Rewrite و غیره)، نسخه‌ی نهایی به‌طور کامل با
> **PHP ساده** بازنویسی شده تا نصب آن فقط «آپلود پوشه» باشد.

کد اصلی پروژه داخل پوشه‌ی [`php-app/`](./php-app) قرار دارد.

- راهنمای کامل نصب روی سرور IIS: [`php-app/DEPLOY.md`](./php-app/DEPLOY.md)
- نسخه‌ی فشرده‌ی قابل‌دانلود کل پروژه: [`release/negahm-media-source.zip`](./release/negahm-media-source.zip)

## ویژگی‌های کلیدی

- طراحی رنگارنگ و پرانرژی، کاملاً راست‌به‌چپ و فارسی.
- گالری نمونه‌کارهای masonry (بدون برش تصویر، بدون فاصله‌ی اضافه).
- هر دسته‌بندی نمونه‌کار یکی از سه نسبت تصویر ثابت را دارد: ۱۶:۹ (افقی)،
  ۹:۱۶ (عمودی/ریلز) یا ۱:۱ (مربع).
- پنل مدیریت کامل در مسیر `/dashbord/app` شامل:
  - مدیریت کارفرمایان (ایجاد/ویرایش/حذف/ترتیب/وضعیت انتشار/ویژه بودن)
  - مدیریت دسته‌بندی‌ها و نمونه‌کارهای هر کارفرما (تصویر و ویدئو)
  - تنظیمات کامل سایت: نام/شعار/لوگو، رنگ‌بندی، فونت (و آپلود فونت
    سفارشی)، متن صفحه‌ی اصلی و درباره‌ی ما، اطلاعات تماس، شبکه‌های
    اجتماعی و متن فوتر
  - مدیریت پیام‌های فرم تماس
  - تغییر رمز عبور مدیر
- پایگاه‌داده‌ی SQLite از قبل با ۳۴ کارفرمای واقعی نگاه مدیا پر شده است.

## راه‌اندازی محلی (برای توسعه/تست)

نیازی به Composer یا artisan نیست — کافی است یک PHP نصب‌شده با
`pdo_sqlite` داشته باشید:

```bash
cd php-app
php -S localhost:8000
```

سپس:

- سایت عمومی: `http://localhost:8000/index.php`
- پنل مدیریت: `http://localhost:8000/dashbord/app/login.php`
  (نام کاربری `Mohusyn`، رمز عبور `Smosh1387` — پیش‌فرض، از داخل پنل
  قابل تغییر است)

## استقرار روی سرور واقعی (IIS)

راهنمای کامل و گام‌به‌گام (شامل پیش‌نیازها، تنظیم دسترسی پوشه‌ها،
عیب‌یابی) در [`php-app/DEPLOY.md`](./php-app/DEPLOY.md) آمده است.
خلاصه: **کل پوشه‌ی `php-app/` را آپلود کنید، به دو پوشه‌ی `data/` و
`uploads/` دسترسی نوشتن بدهید، همین.**
